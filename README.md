## 🌟 Overview

**FitPro Trainer Website** is a modern and responsive fitness portfolio platform created to showcase gym trainers, fitness programs, workout plans, transformations, and professional services in a stylish way.

This website delivers a **high-quality user experience** with modern UI/UX design, animations, responsive layouts, and smooth navigation to attract clients and grow a fitness brand online.

# ⚡ Installation

```bash
# Clone the repository
git clone https://github.com/ShehanHarshaKumara/FitPro-Trainer-Website.git

# Open project folder
cd FitPro-Trainer-Website

# Install dependencies
npm install

# Run development server
npm run dev
```

# 🎨 UI/UX Design

This project is inspired by modern fitness brands and professional portfolio interfaces with:

* Dark futuristic theme
* Smooth animations
* Interactive cards
* Modern typography
* Fitness-focused layouts
* High visual performance

Fitness portfolio inspirations and modern trainer UI trends were referenced from platforms like [Dribbble Fitness Portfolio Designs](https://dribbble.com/search/trainer-portfolio?utm_source=chatgpt.com) and React-based trainer portfolio examples. ([GitHub][1])
